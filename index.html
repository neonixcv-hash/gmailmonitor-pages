Замовлення з пошти —
у локальному обліку.

GmailMonitor допомагає власнику поштової скриньки знаходити вхідні замовлення та зберігати їхні параметри в локальній CRM.

Як працює монітор

  1. Періодично перевіряє Gmail через офіційний API після авторизації власника.
  2. Виявляє нові повідомлення й уникає повторної обробки за їхніми ідентифікаторами.
  3. Передає текст нового листа й обмежений контекст того самого ланцюжка до OpenAI Codex для первинного логічного розбору.
  4. Зберігає факти про замовлення та питання для власника в локальному обліку. Подальшу підготовку друку виконують окремі програми.

Доступ лише для читання

Застосунок запитує gmail.readonly. Поточний монітор не надсилає листів, не створює чернеток, не змінює мітки або стан прочитання, не архівує та не видаляє повідомлення. Вміст вкладень автоматично не завантажується; їхні назви можуть використовуватися під час розбору.

Особисте використання

Програма працює на комп’ютері власника й не пропонує реєстрацію стороннім користувачам. Цей сайт містить лише публічну інформацію про застосунок. Тут немає входу до Gmail, форм завантаження листів чи доступу до CRM.

Дані листів передаються зовнішньому сервісу OpenAI для розбору. Деталі доступу, зберігання й відкликання дозволу наведено в політиці конфіденційності.

GmailMonitor використовує інформацію з Google API відповідно до Google API Services User Data Policy, включно з вимогами Limited Use.
