Політика конфіденційності

Ця політика описує обробку даних особистим застосунком GmailMonitor та його інформаційним сайтом.

1. Хто використовує дані та для чого

GmailMonitor використовується власником авторизованої скриньки для обліку поліграфічних замовлень. Контакт власника й оператора: neonix.cv@gmail.com. Мета обробки — виявлення замовлень, первинний розбір параметрів, зв’язок із наявними записами й показ питань власнику.

2. До яких даних є доступ

Через Gmail API застосунок отримує ідентифікатори повідомлень і ланцюжків, відправника й одержувача, тему, дату, текстові/HTML-частини листа та назви вкладень. Для контексту запитуються до десяти останніх повідомлень того самого ланцюжка. Вміст вкладень поточний монітор автоматично не завантажує.

Дозвіл https://www.googleapis.com/auth/gmail.readonly технічно дає читання пошти. Реалізація застосунку використовує його для пошуку й читання; вона не змінює поштову скриньку.

3. Передавання до OpenAI Codex

Для первинного логічного розбору текст нового листа, його метадані, назви вкладень і зазначений контекст ланцюжка передаються до OpenAI через Codex CLI. Окрема сесія Codex також має доступ до робочої папки проєкту й може читати локальні правила та записи CRM і оновлювати CRM. Тому обробка листів не є виключно локальною.

Застосунок не передає OAuth-токен у текст запиту до моделі. Зберігання й обробка на боці OpenAI залежать від умов сервісу та налаштувань акаунта власника. Ця політика не обіцяє нульового зберігання або конкретного строку видалення на боці провайдера.

4. Локальне зберігання та строки

Облікові записи замовлень, джерела, історія, ідентифікатори оброблених листів, підсумки й діагностика зберігаються на ПК власника. OAuth-токен зберігається в локальному профілі Windows, окремо від публічних сторінок. У програми немає власного публічного сервера для зберігання пошти.

Автоматичного строку очищення CRM і журналів не встановлено: дані залишаються до ручного видалення власником. Резервні копії, якщо створені власником, очищуються окремо.

5. Обмеження використання

Дані використовуються для описаної функції обліку замовлень. Застосунок не продає дані, не використовує їх для реклами, кредитного скорингу чи стеження. Публічний сайт не показує листи або CRM. Власник може переглядати дані й перевіряти результати розбору.

Використання інформації, отриманої через Google API, підпорядковується Google API Services User Data Policy, включно з Limited Use. Передавання до Codex призначене лише для описаної функції розбору замовлень.

6. Відкликання доступу та видалення

Власник може зупинити монітор і відкликати доступ у підключеннях Google-акаунта. Це припиняє подальший доступ до Gmail, але не видаляє вже збережені записи CRM, журнали, резервні копії чи дані на боці OpenAI. Локальні дані видаляються власником окремо; запити щодо даних, оброблених OpenAI, вирішуються через засоби відповідного сервісу.

Для питань або звернень щодо даних: neonix.cv@gmail.com.

7. Інформаційний сайт і зміни політики

На цих сторінках немає власних скриптів аналітики, форм, рекламних засобів або cookies, які встановлює застосунок. Після публікації на GitHub Pages хостинг може обробляти технічні дані запитів, зокрема IP-адресу, відповідно до політики GitHub.

При зміні способу доступу, використання або передавання даних політика оновлюється, а власник має ознайомитися зі змінами до використання нової поведінки.
